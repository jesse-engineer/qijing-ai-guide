# 奇境 AI：中文同人小说创作指南

[官方网站](https://www.fictionalland.com/) · [English](README.en.md) · [快速开始](docs/quickstart.md) · [常见问题](docs/faq.md)

奇境 AI 是面向中文同人小说读者与创作者的 AI 辅助创作平台，提供网页和微信小程序入口。用户可以从一个脑洞、一段场景或已有正文开始，通过对话逐步整理角色、世界观、大纲与章节，并在创作过程中调整剧情方向。

本仓库由奇境 AI 产品方维护，公开使用指南、可复制的创作模板和教学示例。它不包含在线服务的实现代码；公开文档不代表在线服务免费或开源。

## 能做什么

| 创作需要 | 平台能力 |
| --- | --- |
| 整理原作 | 导入 TXT、DOCX、EPUB 小说，整理故事、角色与世界设定资料 |
| 展开脑洞 | 对话讨论人物关系、故事走向、世界观、大纲与章纲 |
| 创作同人与跨作品故事 | 在项目中关联一部或多部原作，结合用户设定展开创作 |
| 写作与修改 | 生成、续写章节，对段落或整章提出修改要求，编辑已保存内容 |
| 持续推进故事 | 结合创作笔记与已保存章节，保留重要设定和创作决定 |
| 检查故事 | 审查创作内容中的跨章矛盾、时间线冲突和设定不一致 |
| 管理成果 | 管理项目、章节和笔记；网页端提供 TXT 导出，受会员权益限制 |

原作检索与章节审核承担不同任务：前者提供原作信息，后者检查正在创作的故事。审核建议需要作者判断，不能保证消除所有 OOC 或连续性问题。

## 从哪里开始

1. 打开[奇境 AI 官网](https://www.fictionalland.com/)，登录并进入创作流程。
2. 选择或上传相关原作，告诉助手你想改变什么、保留什么。
3. 从当前最需要的内容开始：讨论想法、整理设定，或先试写一个场景。
4. 阅读结果，提出具体修改要求，把确认的决定记录下来，再继续下一章。

完整步骤见[快速开始](docs/quickstart.md)。不必先完成所有角色卡和大纲才能动笔。

## 可直接使用的材料

先看[三个模板怎样配合使用](templates/README.md)：从一句脑洞、一次局部修改到下一章的状态核对，每份都有使用时机与填写示范。

- [创作简报模板](templates/story-brief.md)：记录想法、原作边界与当前任务。
- [角色一致性检查表](templates/character-consistency.md)：区分原作事实、合理推断和新增设定。
- [跨章连续性检查表](templates/continuity-review.md)：核对时间、知识、资源与伏笔。
- [同人创作教学示例：《斗罗大陆》](examples/douluo-dalu.md)：展示从设定到改写要求的过程。
- [可复核的体验记录方法](docs/reproducible-review.md)：保留输入、输出和修改前后对照，供教程作者与其他项目复用。

模板可用于奇境 AI，也可用于手工规划。教学示例不是平台实测输出或效果评测。
