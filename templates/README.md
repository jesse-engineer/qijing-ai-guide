# 三个模板怎样配合使用

[返回首页](../README.md) · [斗罗大陆教学示例](../examples/douluo-dalu.md)

这三个模板分别解决开写、修人物、接下一章时的问题。按眼前需要选一份即可，不需要填完三份才能写作，也不需要把整份检查表一次发给 AI。

| 当前卡在哪里 | 使用哪份 | 最少填写内容 | 应得到什么 |
| --- | --- | --- | --- |
| 有脑洞，但不知道怎么开口 | [创作简报](story-brief.md) | 原作、想写什么、暂时不想发生什么 | 一条能直接开始讨论的创作请求 |
| 人物说话或行为不对劲 | [角色一致性](character-consistency.md) | 具体句段、依据、希望保留的内容 | 一条有范围的修改请求 |
| 准备续写，担心前后矛盾 | [跨章连续性](continuity-review.md) | 已发生的结尾状态与正文位置 | 一份下一场景需要承接的事实清单 |

## 以《斗罗大陆》训练番外为例

以下为人工编写的填写示范，不是平台实测结果，也不声称这些训练情节来自原作。

### 开写前：把想法缩成一句话

> 我想写唐三和小舞的一段训练番外，两人在要不要走近路这件事上意见不一样。只参考第一部小说，先帮我选一个合适的时间点，别提前写出后面的秘密。

这句话用到创作简报中的原作、脑洞、待核查问题和边界。角色等级尚未核查，所以不先填一个看起来准确的数字。

### 读完初稿：指出一个具体问题

假如初稿中小舞只负责赞同、没有自己的判断，可以这样要求：

> 这里只改两人争论近路的对话。让小舞指出一个唐三没注意到的现场线索，再由两人一起决定怎么验证。前后的事件顺序不变。

这里是修改方法演示；只有实际初稿出现上述问题时才需要这样改。若原本写得合适，不必为了使用模板强行挑错。

### 接写前：记录已发生的事

假如正文确实写到“两人站在岔路口，决定先探路”，再据正文填写：

| 项目 | 记录示范 | 依据要求 |
| --- | --- | --- |
| 地点 | 岔路口 | 对应正文句段 |
| 行动 | 决定探路，尚未完成验证 | 不把计划写成已经发生 |
| 信物 | 持有人待核对 | 正文没有写就留待确认 |
| 能力 | 本场尚未使用魂技 | 只在正文支持时填写 |
| 下一段 | 验证近路是否可行 | 不直接跳到任务成功 |

## 给教程作者与评测者

引用模板时链接到具体文件；如果修改了字段，注明是改编版。记录真实案例时，保留初始输入、原始输出、修改请求和修订结果，并区分原作依据、作者新增设定与人工判断。单个场景只能说明这一次的表现，不能用来证明长篇稳定性。
