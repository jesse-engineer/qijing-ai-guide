# 跨章连续性检查

| 检查对象 | 核对问题 | 正文位置／证据 | 作者决定 |
| --- | --- | --- | --- |
| 时间 | 事件顺序、路程和持续时间是否一致？ | | |
| 空间 | 人物如何从上一地点到达当前地点？ | | |
| 知识 | 人物何时得知这个秘密？ | | |
| 资源 | 物品、能力、伤势和代价是否承接？ | | |
| 关系 | 态度转变有没有足够铺垫？ | | |

| 设定 | 新章节是否冲突于已确认规则？ | | |

可复制要求：

> 先指出具体证据，再提出修订建议。将确定矛盾、可能缺少交代和个人风格偏好分开。不要自动删除有意保留的悬念，也不要声称未提供的章节已经检查过。
